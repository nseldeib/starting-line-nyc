Five ways in.

  • Open

    First come, first served until the field fills. Popular NYRR races can sell out in hours, so set a reminder for the opening minute.Ted Corbitt 15K, Queens 10K

  • Lottery

    Apply during a window, then wait for the drawing. Applying early gives you no better odds; missing the deadline means no chance.NYC Half, TCS New York City Marathon

  • Time qualifier

    Run a qualifying time in a set window before the race edition you want. We show which edition each window applies to.

  • Charity

    Guaranteed entry in exchange for a fundraising commitment with an official charity partner.

  • Membership

    Some races need a club membership or a completed set of races in the prior year, like NYRR’s 9+1 program.
